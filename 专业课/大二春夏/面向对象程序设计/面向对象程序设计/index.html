    C++操作案例¶

    new和delete¶

    int* psome=new int[10];

    reference¶

    char &r=c;
    局部变量、全局变量定义时就得写清楚
    参数不用直接赋值
    不可改变，不然容易造成含义不明
    int &*p #illegal for pointer to reference
    void(int* &p) #reference to pointer is okay
    作用：可以降低调用开销

    const¶

    const int z = y;
    储存时尽量不用内存，而直接以table的形式呈现

    run_time constants
    静态数组不可以用run_time constants定义长度

    cin>>x;
    const int size = x;
    double classA[size]; //error

    const for aggregates
    也不可以用其来定义静态数组的长度，但是原因与上述不同。原因是虽然初始化时有确定的值，但是这些值在内存中。有些编译器只知道定义了一个常量数组，但是并不关心数组中具体的数值。

    Pointers and const¶

    char *const q = "abc" //指针不能改，指向的内容可以改;

    const char*p = "ABCD"; //指针指向的内容不能改，指针可以改
    注意：修改指针后，新指向的内容也不能改

    实际方法

    *在const前，指针是常量

    char *s = "Hello,world"; //最好不要修改s指向的内容 可以采用 char s[] = "Hello,world";

    conversions:
    不用explicit cast时，不能把常量对象转换为非常量

    函数调用：
    pass by const value（有效）
    return by const value（没啥用）
    pass and return by reference（比较高效，不用花费很多内存；又可以不像指针那样让用户去修改内容）
